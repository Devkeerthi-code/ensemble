  "permissions": {
    Rules for what Claude Code may do without asking you first.
        "allow": ["Bash(npm run test:*)", "Bash(npm run lint)"],
    It can run your tests and linter on its own. These only read your code and report back, so they are safe.
        "ask": ["Bash(git commit:*)", "Edit(package.json)"],
    It must ask before committing or changing your dependencies. You chose “Balanced”, so these need a yes from you.
        "deny": ["Read(.env)", "Bash(git push:*)"]
    It can never read your secrets file or push to GitHub. You stay in control of what leaves your laptop.
        "allow": ["Bash(rm:*)"]
    Risky, off by default. Lets it delete any file without asking. Useful for big refactors, but a wrong path can remove work that is not committed.
      }

    End of the permissions block.

    Allow deleting files without asking

    Only turn this on if your work is committed often. Ensemble will add a reminder to CLAUDE.md to commit before large deletes.

    • Agent file is in the wrong folder

      agents/code-reviewer.md

      Claude Code only looks for subagents in .claude/agents/. This one will never load.

      - agents/code-reviewer.md
      + .claude/agents/code-reviewer.md

    • Name has a space, so the frontmatter is invalid

      code-reviewer.md · line 2

      Agent names must be lowercase with hyphens. Missing description too, so Claude can’t tell when to use it.

      - name: code reviewer
      + name: code-reviewer
      + description: Reviews the current diff for bugs and unclear code. Use after edits.

    • A reviewer can run any shell command

      code-reviewer.md · line 3

      A reviewer only needs to read. Giving it Bash means it could change files while “reviewing”.

      - tools: Read, Grep, Bash
      + tools: Read, Grep, Glob

    • No AGENTS.md, so Codex gets no rules

      project root

      You have CLAUDE.md. We can translate it for Codex so both tools follow the same rules.
